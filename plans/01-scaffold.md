# Plan 01: Scaffold and core loop

Part of the Claude Desktop Resource Monitor build. Full requirements: [`../REQUIREMENTS.md`](../REQUIREMENTS.md). Execution order and rationale: [`index.md`](index.md).

## Context

The project is a macOS terminal tool (`monitor.py`) that watches Claude Desktop's resource usage, with emphasis on the Cowork feature's local Linux VM. It is observability only: it samples, logs, and flags; it never modifies anything. It is a single Python script run through **uv**, with tool versions pinned by **mise**.

This plan creates the project skeleton that every later plan plugs into: tooling, CLI, the poll loop, the JSONL log, and headless output. No real metrics yet: collectors are stubs.

## Goal

`uv run monitor.py --no-tui` runs a poll loop at the configured interval and writes a well-formed JSONL session log, with clean shutdown on Ctrl-C/SIGTERM.

## Prerequisites

- mise installed (reference machine: mise 2026.9.11).
- Git repo at the project root containing `REQUIREMENTS.md`.

### Component contracts

These interfaces are fixed here; later plans implement them.

- **Collector**: object with `collect(now: float) -> dict` returning a fragment merged into the sample, `close() -> None`. Plan 01 registers stub collectors that return `{}`.
- **Analyzer**: `analyze(sample: dict) -> tuple[dict, list[dict]]` returning `(derived, flag_events)`. Plan 01 ships a pass-through (`({}, [])`).
- **Renderer**: `start()`, `render(sample, derived, active_flags)`, `on_flag(event)`, `poll_keys(timeout: float) -> list[str]`, `stop()`. Plan 01 ships `HeadlessRenderer`. `poll_keys` sleeps for `timeout` (`time.sleep`) and returns `[]`.

### Sample record shape (data contract)

All sizes in **bytes**, rates in **bytes/s**, CPU in **% of one core**, times in seconds. Keys are filled in by the owning plan; missing sections are simply absent.

```json
{
  "type": "sample", "ts": "2026-09-25T21:40:03.123+08:00", "elapsed": 12.004, "seq": 4,
  "claude": {"running": true, "main_pid": 87512, "coalition_id": 11603},
  "processes": [ ... ],                 // Plan 03
  "roles": { "<role>": { ... } },       // Plan 03
  "total": { ... },                     // Plan 03
  "cli": { ... },                       // Plan 03 (--include-cli only)
  "trace_io": { ... },                  // Plan 03 (--trace-io only)
  "paths": { "<name>": { ... } },       // Plan 04
  "bundle": { ... },                    // Plan 04
  "swap": { ... },                      // Plan 05
  "derived": { ... },                   // Plan 06
  "active_flags": [ "<flag id>", ... ]  // Plan 06
}
```

Other record types:

```json
{"type": "session_start", "ts": ..., "elapsed": 0.0, "config": {<all CLI values>}, "versions": {...}, "host": {...}}
{"type": "flag", "ts": ..., "elapsed": ..., "id": "cpu:renderer", "state": "raised|cleared|event", "metric": ..., "value": ..., "threshold": ..., "message": "..."}
{"type": "marker", "ts": ..., "elapsed": ..., "label": "started Cowork task"}
{"type": "session_end", "ts": ..., "elapsed": ..., "reason": "quit|signal|error"}
```

### CLI (all flags from REQUIREMENTS §6)

| Flag | Default | Validation |
|---|---|---|
| `--interval SEC` | 3 | float, 2 ≤ x ≤ 5 |
| `--full-rescan SEC` | 300 | float, > 0 |
| `--cpu-threshold PCT` | 30 | float, > 0 |
| `--cpu-window SEC` | 60 | float, ≥ interval |
| `--write-threshold SIZE` | 1MB | size → bytes/s |
| `--budget-warn PCT` | 80 | 0 < x ≤ 100 |
| `--mem-growth PCT` | 50 | > 0 |
| `--bundle-growth SIZE` | 1GB | size |
| `--bundle-rate SIZE` | 100MB | size (per 10 min) |
| `--log PATH` | `./logs/monitor-<YYYYmmdd-HHMMSS>.jsonl` | parent dir created |
| `--no-tui` | off | |
| `--include-cli` | off | |
| `--trace-io` | off | |
| `--support-dir PATH` | `~/Library/Application Support/Claude` | `expanduser`; need not exist |

Size parsing: accepts a plain integer (bytes) or a number with a suffix. `KB`/`MB`/`GB` are decimal (10³ⁿ), `KiB`/`MiB`/`GiB` are binary (2¹⁰ⁿ). Suffixes are case-insensitive, and a trailing `/s` is allowed.

### Main loop

1. Parse CLI, resolve log path, open log (line-buffered text, `flush()` after each record).
2. Write `session_start`: config, versions (Python, psutil, rich, watchdog, macOS via `platform.mac_ver()`, Claude.app `CFBundleShortVersionString` via `plistlib` if present), host (`sysctl hw.model`, CPU count, `hw.memsize`).
3. Pick renderer: headless if `--no-tui` or `not sys.stdout.isatty()`; otherwise TUI (Plan 07; until then, fall back to headless).
4. Loop with a **monotonic deadline schedule** (`next = start + seq × interval`; skip missed ticks rather than bursting): collect from every collector, merge into the sample, analyze, write the sample and each flag event, call the renderer. Between ticks, call `renderer.poll_keys(until_deadline)`.
5. SIGUSR1: write a `marker` record with `label: "SIGUSR1"` at the next tick. This gives headless runs a way to mark events, e.g. `kill -USR1 <pid>` before starting a Cowork task.
6. SIGINT/SIGTERM: set a stop flag; the loop exits after the current tick, writes `session_end`, closes collectors, stops the renderer. On an unhandled exception, write `session_end` with `reason: "error"` and the traceback string, then re-raise.

### Headless renderer (H-1, H-2)

- At start, print one line to stderr: log path and interval.
- For each flag event: `HH:MM:SS FLAG <state> <id> value=<v> threshold=<t> <message>`.
- Nothing is printed per sample.

## Plan-level decisions (not specified in REQUIREMENTS.md)

- Tests use `pytest` as a **dev-only** dependency group; tests live in `tests/`. The application stays a single script.
- `session_end` record type added (clean-shutdown evidence for long runs).
- Size flags accept decimal and binary suffixes as described above.
- Missed ticks are skipped, not replayed.
- SIGUSR1 writes a marker (headless runs have no keyboard input for `m`).
